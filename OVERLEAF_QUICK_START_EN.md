# Overleaf Quick Start

## What is Overleaf?

Overleaf is an online service for editing LaTeX documents and compiling them to PDF in a web browser. You do not need to install LaTeX on a university computer. `report/report.tex` reads the `.tex` tables and `.pdf` figures generated by R or Stata.

## Create an account

1. Open https://www.overleaf.com/register.
2. Register with Google, ORCID, email and password, or your university's SSO.
3. After signing in, choose `New Project` and create a `Blank Project`. Alternatively, ZIP the supplied Overleaf folder and select `Upload Project`.
4. Open `report/report.tex` and select `Recompile` to confirm that a PDF appears. If Overleaf does not choose that file automatically, set it as the main file.

## Free plan (checked September 2026)

The free plan includes:

- unlimited projects;
- one collaborator per project;
- the basic compile timeout;
- the previous 24 hours of document history; and
- ready-to-use templates.

The free plan should be sufficient for an ordinary individual weekly assignment. A paid plan may be needed for a complex document that exceeds the basic compile timeout, extended document history, track changes, or external integrations.

Plan terms may change. Check the official page for current limits:

- Plans & Pricing: https://www.overleaf.com/user/subscription/plans
- Learn LaTeX in 30 minutes: https://www.overleaf.com/learn/latex/Learn_LaTeX_in_30_minutes

## Use Overleaf with R or Stata

1. Run `code/analysis.R` or `code/analysis.do` from the project folder.
2. The script writes `.tex` tables and `.pdf` figures into `output/`. `report/report.tex` already points at those files.
3. Select `Recompile` and inspect the PDF.
4. After changing the analysis, run the script again and upload the new files in `output/`.
