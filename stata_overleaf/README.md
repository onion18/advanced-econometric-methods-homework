# Stata + Overleaf

Copy this folder for your assignment. The finished sample is `example/stata_overleaf/`. Do not edit the sample.

| Folder | Contents |
|---|---|
| `data/` | Original data for the assignment |
| `code/` | `analysis.do`. Run this from the project folder |
| `output/` | `.tex` tables and `.pdf` figures written by `analysis.do` |
| `report/` | `report.tex`. This is the Overleaf report |
| `ado/` | User-written Stata commands for a public PC |
