# R + Overleaf

Copy this folder for your assignment. The finished sample is `example/r_overleaf/`. Do not edit the sample.

| Folder | Contents |
|---|---|
| `data/` | Original data for the assignment |
| `code/` | `analysis.R`. Run this from the project folder |
| `output/` | `.tex` tables and `.pdf` figures written by `analysis.R` |
| `report/` | `report.tex`. This is the Overleaf report |
