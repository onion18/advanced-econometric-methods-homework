# R Markdown

Copy this folder for your assignment. The finished sample is `example/r_markdown/`. Do not edit the sample.

| Folder | Contents |
|---|---|
| `data/` | Original data for the assignment |
| `code/` | Additional R scripts, if you use any |
| `output/` | Tables and figures written by code |
| `report/` | The report. Open `replication_template.Rmd` |
