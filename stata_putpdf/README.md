# Stata + putpdf

Copy this folder for your assignment. The finished sample is `example/stata_putpdf/`. Do not edit the sample.

| Folder | Contents |
|---|---|
| `data/` | Original data for the assignment |
| `code/` | `replication_template.do`. Run this from the project folder |
| `output/` | The report PDF and figures written by the do-file |
| `report/` | Unused by this route. putpdf writes the PDF into `output/` |
