# Example data

- `scatter_simulation.csv` and `event_study_simulation.csv` are simulated datasets. In the R templates, `code/generate_simulation_data.R` recreates them with fixed seeds.
- `penguins.csv` contains the `penguins` data from `palmerpenguins` 0.1.1. The CSV is included so the templates do not need to install that package.

## Dataset reference

Horst, A. M., Hill, A. P., & Gorman, K. B. (2020). *palmerpenguins: Palmer Archipelago (Antarctica) penguin data* (R package version 0.1.0) [Data set]. Zenodo. https://doi.org/10.5281/zenodo.3960218
