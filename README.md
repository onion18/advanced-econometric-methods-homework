Open `Student_Replication_Guide_EN.pdf` first.

課題には、空のルートフォルダを1つコピーして使ってください。`example/` は完成見本です。編集して提出しないでください。

Copy one blank route folder for your assignment. `example/` is a finished sample. Do not edit it for submission.

| Folder | What is inside | Open this |
|---|---|---|
| `r_quarto/` | Blank R + Quarto project | `report/replication_template.qmd` |
| `r_markdown/` | Blank R Markdown project | `report/replication_template.Rmd` |
| `r_overleaf/` | Blank R + Overleaf project | `code/analysis.R`, then `report/report.tex` |
| `stata_overleaf/` | Blank Stata + Overleaf project | `code/analysis.do`, then `report/report.tex` |
| `stata_putpdf/` | Blank Stata project that writes a PDF directly | `code/replication_template.do` |
| `example/` | One finished sample for each route above | `example/README.md` |

Each blank folder contains `data/` (original data), `code/` (scripts), `output/` (files written by code), and `report/` (the report).
